<h1 align="center">The Finals – Weapon Datasheet</h1>

<p align="center"><a href="https://jrd5656.github.io/the-finals-datasheet/">🔗 Live site →</a></p>

A single-page web app that presents the official **The Finals** weapon datasheet in a clean, interactive format. Built from the game's live spreadsheet, with analytics (scatter plot + bars), version-to-version diffing, and side-by-side compare.

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Single-page app – renders all UI from the inlined latest weapon data; older versions are fetched on demand from `snapshots/` |

## Auto-updates

`.github/workflows/update.yml` runs on a schedule (daily 06:00 UTC) and on manual dispatch. It re-fetches the datasheet; if a new version appears, it makes that version the inlined `LATEST`, extends the `VERSIONS` manifest, writes a copy under `snapshots/`, and commits back to `gh-pages`.

## Files

- `index.html` – the app (all UI + inlined latest weapon data + version manifest)
- `update_snapshots.py` – data pipeline (Google Sheet → `index.html` + `snapshots/`)
- `.github/workflows/update.yml` – CI automation
- `snapshots/` – per-version JSON snapshots for diffing (generated by the workflow)
- `background2.jpg` – page background image
- `icon.png` – repo icon
